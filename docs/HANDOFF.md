# Codex 인수인계

## 현재 상태

이 저장소는 LF몰 첫구매·가입·앱 설치·앱푸시 수신동의 실적을 월별·주별·일별로 조회하는 대시보드다. 2026-09-16 기준 GitHub `main`의 최신 확인 커밋은 `f78f8f5`(v23)이며, 인수인계본은 이 커밋까지 받아 왔다.

저장소에는 실적 데이터와 실제 KPI 목표가 없다. 여러 사용자가 같은 배포 주소를 열어 각자 `.json.gz` 백업을 업로드한다. 업로드된 실적은 서버/저장소가 아닌 **그 사용자의 브라우저 IndexedDB**에만 저장된다. 개발자의 로컬 폴더나 로컬 빌드는 조회에 필요하지 않다. 새 실적을 모두에게 자동 배포하는 구조가 아니므로, 각 사용자가 최신 백업을 받아 다시 열어야 한다.

이번 인수인계에서는 화면·기능·산식을 변경하지 않고 Codex/ChatGPT가 바로 이어서 작업할 수 있도록 작업 기준과 운영 문서를 추가했다.

## Claude에서 마지막으로 반영된 변경

- v20: 메모에 붙일 기간을 선택하고 모든 표의 머리행을 고정
- v20.1: KPI 유입·가입 카드에 연간 목표 숫자와 달성률을 함께 표시
- v21: 메모를 리뷰/계획 두 칸으로 분리하고 고정 머리행 겹침을 보정
- v22: 빈 메모 칸 복제 문제를 수정하고, 기간이 겹치는 메모를 “이 화면 조건”에 노출
- v23: 표의 `top` 행과 상단 헤더 CSS 충돌을 제거하고, 고정 머리행의 갱신 타이밍을 보강

이 변경은 모두 `dashboard.html`에 있으며 확인 시점의 `main`에 포함되어 있다. 원격에는 `main` 외 별도 브랜치가 없다.

Claude의 v23 완료 보고에 따르면 표 내부 고정 행, 스크롤 위치, 헤더 겹침·누락·폭을 포함한 216개 조합에서 실패가 없었고 GitHub Pages 빌드가 완료됐다. 인수인계 측에서는 공개 `dashboard.html`이 HTTP 200을 반환하며 v23의 `header.top` 선택자와 고정 헤더 타이머 보강, 백업 업로드 UI를 포함하는 것을 확인했다. 이 확인은 개인 백업의 실제 수치 대조를 대신하지 않는다.

## 수정할 때 보는 순서

1. `AGENTS.md`에서 불변 조건을 확인한다.
2. 화면/계산은 `dashboard.html`, 로컬 데이터 빌드는 `build_data.py`, 브라우저 추가 병합은 `merge.js`, 다운로드는 `export.js`에서 찾는다.
3. 지표 또는 기간 변경이면 `docs/METRICS.md`와 화면의 “지표 정의 · 집계 기준” 문구를 함께 맞춘다.
4. 파싱 또는 병합 변경이면 Python과 JavaScript 구현의 결과를 같은 입력으로 대조한다.
5. `docs/DATA_OPERATIONS.md`의 검증을 거친 뒤, 사용자가 요청했을 때만 배포한다.

## 현재 제품 계약

- 기본 보기: 월별, 일평균, 최신 기간, 전체 채널, 전체 회원구분, 전년비
- 단위: 월별/주별/일별, 일평균/누계, 전년비/직전 기간 비교
- 필터: 연도, 기준 기간, 채널 복수 선택, 회원구분 복수 선택
- 영역: 실적 요약, 흐름 차트, 실적 표, 상품 구성, 앱 설치·수신동의, KPI, 인사이트, 메모, 다운로드
- 개인 상태: 보기 설정은 `fp-dashboard-v4`, 메모는 `fp-dashboard-memos`, 활성 백업은 IndexedDB `fp-dashboard-backup`
- 백업 형식: `fp-dashboard-backup`, version 1

## 특히 조심할 곳

- `dashboard.html`은 CSS·화면·계산·저장 로직이 한 파일에 모여 있다. 전체 재작성보다 관련 함수만 작게 수정한다.
- 월/주/일 계산은 서로 다른 트래픽 기준과 비교 기간 규칙을 가진다. 한 화면만 보고 공용화하면 지표가 달라질 수 있다.
- 로컬 빌드와 브라우저 병합은 독립 구현이다. 어느 한쪽만 고치면 같은 raw를 넣어도 결과가 달라진다.
- 백업에는 실적과 KPI, 상품, 메모가 들어갈 수 있다. 실제 파일은 공개 저장소에 올리지 않는다.
- PDF는 외부 CDN의 html-to-image/jsPDF를 사용하며, 차단되면 인쇄 창으로 대체된다.
