# AI 질문창·특수기간 비교 설계

## 목적

사용자가 대시보드에서 채팅하듯 자연어로 특수기간을 질문하면, 브라우저가 입력을 규칙 기반으로 해석하고 기존 공식 산식으로 전·중·후 실적을 계산해 비교표와 핵심 요약을 보여 준다.

첫 단계에서는 GPT/API, 외부 전송, API 키, 서버 저장을 사용하지 않는다. 승인된 예시 화면의 흐름을 기존 대시보드에 적용한다.

## 대표 사용 예

입력:

`24년 추석 9월 14-18, 25년 추석 10월 3-9, 전후 영향 알려줘`

해석:

- 2024년 추석: 2024-09-14~2024-09-18
- 2025년 추석: 2025-10-03~2025-10-09
- 전 기간: 각 특수기간 직전 7일
- 후 기간: 각 특수기간 직후 7일
- 지표·채널·회원구분: 질문에 없으므로 현재 화면 선택값

응답:

1. 해석한 조건
2. 행사별 전·중·후 비교표
3. 전→중, 중→후 변화
4. 행사 중 실적의 연도 간 비교
5. 관찰 가능한 핵심 변화 3~5줄

## 적용 및 배포 전략

승인된 예시 UI를 실제 `dashboard.html`에 적용한다. 질문창은 “인사이트 자동 요약” 바로 아래, 메모 영역 바로 위에 두고 기본 상태는 접힘으로 한다. 정적 페이지와 Streamlit 래퍼 모두 같은 `ai_question.js`를 사용한다.

별도 모형 데이터는 사용하지 않는다. 사용자가 올린 실제 백업과 현재 대시보드 상태를 사용해 검증한 뒤, 최신 원격 변경을 다시 동기화하고 전체 회귀 테스트를 통과한 버전을 배포한다.

## 자연어 해석 범위

### 날짜

- 연도: `24년`, `2024년`, `2024`
- 범위: `9월 14-18`, `9/14~18`, `9월 14일부터 18일까지`
- 여러 행사: 쉼표, 줄바꿈, `그리고`, `vs`, `비교`로 구분
- 행사명은 날짜 범위 앞뒤의 일반 텍스트에서 추출한다.

연도 또는 시작·종료일을 확정할 수 없으면 계산하지 않고 어떤 부분을 다시 적어야 하는지 답한다. 존재하지 않는 날짜, 종료일이 시작일보다 빠른 범위, 데이터 범위를 완전히 벗어난 기간도 오류로 처리한다.

### 전·후 기간

- 기본값: 전 7일, 후 7일
- `전후 14일`: 전·후 각각 14일
- `전 3일 후 10일`: 서로 다른 길이 지정

전 기간은 특수기간 시작일 바로 전날까지, 후 기간은 종료일 다음 날부터 연속 날짜로 만든다.

### 지표와 필터

- 질문에 지표가 없으면 기존 핵심 지표 전체를 사용한다.
- 지원 지표: 첫구매 거래액, 고객수, 객단가, 비회원 트래픽, 가입자수, 가입률, 당일가입 CR, 첫구매율.
- 질문에 채널 또는 회원구분이 있으면 그 조건을 우선한다.
- 질문에 없으면 현재 화면의 채널·회원구분 선택값을 사용한다.
- 알아듣지 못한 채널·회원구분은 조용히 무시하지 않고 인식 실패로 표시한다.
- 상품/BPU 드릴다운, 앱 설치, 앱푸시, KPI 질문은 첫 버전 범위에서 제외한다.

## 계산 규칙

### 공식 산식 재사용

`dashboard.html`의 `compute()`, `delta()`, 기본 시리즈와 채널·회원구분 키 규칙을 단일 기준으로 사용한다. 질문창 전용 산식을 별도로 복제하지 않는다.

`compute()`는 기존 호출 결과를 바꾸지 않는 선택적 계산 모드 인자를 받도록 확장한다. 기존 화면은 현재 `S.mode`, 질문창은 명시적 `avg` 또는 `sum`을 전달한다. 이를 통해 화면 상태를 임시 변경하지 않고 같은 공식 계산 경로를 사용한다.

### 기간 길이 차이

- 거래액·고객수·트래픽·가입자수: 일평균을 주 비교값으로 사용하고 기간 합계도 함께 표시한다.
- 객단가·가입률·당일가입 CR·첫구매율: 기간의 공식 분자·분모를 다시 집계해 계산한다.
- 비교 증감: 비율 지표는 `%p`, 나머지는 증감률 `%`를 사용한다.
- 데이터가 요청 기간의 절반 미만이면 기존 `compute()` 규칙에 따라 값을 내지 않는다.

### 비교

각 행사에 대해 다음을 계산한다.

- 전 대비 행사 중 변화
- 행사 중 대비 후 변화
- 전 대비 후 변화

행사가 둘 이상이면 같은 지표의 행사 중 일평균/비율을 행사끼리 추가 비교한다. 기간 길이가 달라도 합계끼리 직접 우열을 판단하지 않는다.

## 화면 구성

질문창은 기존 “인사이트 자동 요약”과 구분되는 접이식 섹션으로 둔다.

- 위치: `#insightSec` 바로 다음, `#memoSec` 바로 앞
- 초기 상태: 기본 접힘
- 제목: `AI 실적 질문`
- 안내: `현재는 GPT 연결 없이 브라우저 안에서 계산합니다`
- 대화 영역: 사용자 질문과 대시보드 답변을 말풍선 형태로 누적
- 입력창: 여러 줄 자연어 입력, Enter 전송, Shift+Enter 줄바꿈
- 예시 질문 버튼: 추석 비교 문장을 입력창에 채움
- 답변 상단: 해석된 기간·전후 일수·지표·필터
- 본문: 전·중·후 표와 요약

질문 기록은 첫 버전에서 메모·백업·localStorage에 저장하지 않는다. 새로고침하면 사라진다.

## 상승 시점 및 액션 시작일

- 질문에 포함된 행사별로 행사 시작 28일 전부터 행사 종료 14일 후까지 일별 곡선을 만든다.
- 기준선은 행사 시작 28일 전부터 15일 전까지의 일평균이다.
- 상승 시작점은 3일 이동평균이 기준선보다 5% 이상 높고, 이후 3개 이동평균 중 2개 이상이 같은 기준을 유지하는 첫날이다.
- 예측에는 상승 시작점을 계산할 수 있는 과거 행사가 최소 2개 필요하다. 두 행사 미만이면 임의 예측 없이 `예측 근거 부족`으로 표시한다.
- 여러 행사의 상승 시작 상대일 중 중앙값을 예상 상승 시점으로 사용한다.
- 권장 액션 시작일은 예상 상승 시점보다 **14일 전**으로 고정한다.
- 미래 행사 날짜가 질문에 포함되면 달력 날짜를 표시하고, 그렇지 않으면 `행사 시작 D-n` 형태의 상대 기준으로 안내한다.
- 상승률은 인과관계나 보장값으로 표현하지 않고 과거 관찰 범위로만 표시한다.

## 답변 문구 원칙

- 원인으로 단정하지 않고 관찰된 변화만 말한다.
- `행사 기간에 거래액이 전 7일 대비 증가했습니다`처럼 기준 기간과 방향을 함께 쓴다.
- 데이터가 부족한 지표는 생략하지 않고 `데이터 부족`으로 표시한다.
- 질문 해석 결과를 모든 답변에 먼저 보여 사용자가 계산 기준을 검증할 수 있게 한다.
- GPT처럼 보이는 자유 생성 문장은 쓰지 않고 계산된 값과 고정된 규칙 문장만 사용한다.

## 오류 처리

- 날짜 없음: 날짜 형식 예시를 보여 준다.
- 모호한 연도/범위: 해석 후보를 임의 선택하지 않고 다시 질문하도록 안내한다.
- 데이터 범위 밖: 사용 가능한 첫날·마지막 날을 함께 보여 준다.
- 필터 미인식: 지원하는 채널·회원구분 목록을 보여 준다.
- 일부 기간만 데이터 부족: 계산 가능한 행사와 부족한 행사를 구분해 표시한다.

## 테스트 전략

구현 전에 실패하는 테스트를 먼저 추가한다.

### 규칙 테스트

- 대표 질문에서 두 행사와 날짜 범위를 정확히 추출
- 두 자리 연도를 2000년대로 변환
- 기본 전·후 7일과 사용자 지정 일수 계산
- 월말·연말을 넘는 전·후 기간
- 잘못된 날짜와 모호한 입력 거부
- 질문 필터 우선, 미지정 시 현재 화면 필터 사용

### 계산 테스트

- 같은 날짜·필터에서 질문창 값과 `compute()` 값이 일치
- 합산 지표의 일평균과 합계
- 비율 지표의 재집계와 `%p` 증감
- 기간 길이가 다른 행사 간 비교에서 일평균 사용
- 데이터 절반 미만일 때 `데이터 부족`
- 기존 화면 계산 결과가 변경되지 않음

### 실제 백업 검증

`D:\류은지_AI\first-dashboard\backup\첫구매대시보드_백업_데이터20260920.gz`를 로컬 브라우저에 올려 대표 질문을 실행한다. 표시된 전·중·후 날짜, 전체/채널/회원구분 값, 요약 문장을 원시 기본 지표로 독립 재계산해 대조한다. 백업과 원천 데이터는 커밋하지 않는다.

## 완료 기준

- 로컬 미리보기에서 자연어 질문→조건 해석→표→요약 흐름이 동작한다.
- 외부 네트워크 요청과 API 키 사용이 없다.
- 질문창 수치가 기존 공식 계산과 일치한다.
- 기존 대시보드 기능과 지표 결과가 그대로다.
- 실제 백업 검증 결과와 제한 사항을 사용자에게 보고한다.
- 질문창은 인사이트 자동 요약 바로 아래에서 기본 접힘으로 표시된다.
- 상승 예상 시점보다 14일 전을 권장 액션 시작일로 표시한다.
- 최신 원격 변경을 포함한 상태에서 검증 후 배포한다.
