# AI 실적 질문 예시 화면 저장 기능 설계

## 목적

독립 예시 HTML에서 질문 입력을 단순화하고, 생성된 AI 인사이트를 근거 데이터와 함께 저장하고 다시 확인할 수 있게 한다. 실제 대시보드에는 예시 화면을 검토한 뒤 동일한 구조를 적용한다.

## 예시 화면 변경 범위

- 질문 입력란의 예시 문구를 제거한다.
- 입력란 아래의 예시 질문 버튼 세 개를 제거한다.
- 각 AI 인사이트 헤더에 `저장` 버튼을 배치한다.
- 저장이 끝나면 같은 버튼을 `저장됨` 상태로 바꾸고 중복 저장을 막는다.
- 상단에 `저장한 인사이트` 버튼과 저장 건수를 표시한다.
- `저장한 인사이트`를 누르면 저장 목록을 펼치거나 접을 수 있다.
- 저장 목록에서는 저장 시각, 질문, 인사이트 제목을 보여 주고, 본문과 근거 데이터는 필요할 때만 펼쳐 본다.
- 저장 항목은 개별 삭제할 수 있다.

## 저장 데이터

한 건의 저장 항목은 다음 값을 하나의 묶음으로 가진다.

- 고유 ID
- 저장 시각
- 사용자 질문
- AI 인사이트 제목과 본문
- 핵심 지표
- 권장 액션
- 질문에서 해석한 기간·채널·회원구분·BPU·카테고리 조건
- 답변 계산에 사용한 근거 데이터 표
- 데이터 기준일과 산식 설명

예시 HTML에서는 이 데이터를 브라우저 `localStorage`에 저장해 새로고침 후에도 유지한다.

## 실제 대시보드 반영 원칙

- Gemini는 질문과 답변 문장을 생성하되, 근거 데이터 값은 기존 대시보드 공식 산식의 계산 결과만 사용한다.
- 질문마다 해석된 조건과 계산 결과로 근거 데이터 표를 새로 만든다. 고정 예시값을 재사용하지 않는다.
- 저장된 인사이트 배열을 기존 백업 다운로드 데이터에 포함한다.
- 백업 불러오기 시 저장된 인사이트도 함께 복원한다.
- 같은 고유 ID가 있으면 최근 저장본 하나만 유지한다.
- 저장된 인사이트는 원본 실적을 다시 계산한 결과가 아니라, 저장 당시의 질문·답변·근거 데이터 스냅샷으로 취급한다.

## 오류 처리

- 브라우저 저장 공간을 사용할 수 없으면 저장 버튼 가까이에 실패 이유를 표시한다.
- 내용이 없는 답변은 저장하지 않는다.
- 손상된 저장 항목은 목록에서 제외하되 다른 정상 항목은 계속 표시한다.
- 백업에 저장된 인사이트가 없어도 기존 백업 불러오기는 정상 동작해야 한다.

## 검증 기준

- 입력란에 예시 문구와 예시 질문 버튼이 보이지 않는다.
- 질문을 두 번 하면 답변 두 개가 순서대로 누적된다.
- 근거 데이터는 모든 답변에서 기본적으로 접혀 있다.
- 질문 종류에 따라 예시 근거 데이터의 조건과 표 값이 달라진다.
- 저장 후 새로고침해도 저장 목록에 남는다.
- 같은 답변을 반복 저장할 수 없다.
- 저장 항목을 삭제하면 새로고침 후에도 다시 나타나지 않는다.
- 375px, 768px, 1024px, 1440px 폭에서 가로 스크롤 없이 사용할 수 있다.

## 제외 범위

- 예시 HTML에서 실제 Gemini API를 호출하지 않는다.
- 예시 HTML에서 여러 사용자 간 서버 동기화를 제공하지 않는다.
- 실제 대시보드 코드는 예시 화면 승인 전에는 변경하지 않는다.
