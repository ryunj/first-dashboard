# AI 실적 질문 근거 범위와 분석 깊이 개선 설계

## 목표

사용자가 짧게 질문해도 기존 대시보드 공식으로 계산한 핵심 지표를 충분히 분석하고, 근거 데이터에는 질문에서 요청한 실적 영역만 표시한다. 앱·푸시·KPI·상품 실적은 사용자가 해당 영역을 명시했을 때만 포함한다.

## 질문 해석 규칙

1. 지표를 쓰지 않은 일반 실적 질문은 자동 요약과 동일한 핵심 지표 전체를 기본값으로 사용한다.
   - 첫구매 거래액, 첫구매 고객수, 첫구매 객단가
   - 비회원 트래픽, 가입자수, 가입률, 당일가입 CR, 첫구매율
2. 지표를 명시하면 명시한 지표만 계산·표시한다.
3. 앱 설치·앱푸시·회원 앱 지표는 `앱`, `설치`, `푸시`, `수신동의` 등 해당 의도가 있을 때만 포함한다.
4. KPI는 `KPI`, `목표`, `달성률` 의도가 있을 때만 포함한다.
5. 상품 실적은 `BPU`, `카테고리`, `브랜드`, `상품` 등 상품 차원을 요청했을 때만 포함한다.
6. `모든 실적`을 명시한 경우에만 core·app·kpi·product 전체를 포함한다.
7. Gemini가 위 범위를 넓혀 반환하더라도 서버와 브라우저가 질문 의도를 다시 검증해 요청하지 않은 영역을 제거한다.

## 근거 데이터 범위

브라우저의 기존 공식 계산 결과 중 최종 해석된 `families`, `metrics`, `appMetrics`, `dimensions`에 해당하는 부분만 근거 데이터에 넣는다. 화면의 접힌 `근거 데이터 보기`와 Gemini로 보내는 제한된 집계 근거는 동일한 자료를 사용한다.

- core만 요청: 핵심 실적 표만 표시
- 특정 core 지표 요청: 해당 행만 표시
- app 요청: 요청한 앱·푸시 지표만 표시
- KPI 요청: KPI 표 추가
- 상품 차원 요청: 요청한 차원의 상품 표 추가
- 전체 실적 요청: 모든 영역 표시

화면의 현재 채널·회원·BPU·카테고리 필터를 상속하는 기존 동작은 유지한다. 질문 실행은 화면 필터를 변경하지 않는다.

## AI 답변 구조

Gemini 인사이트는 다음 순서와 역할을 갖는다.

1. 핵심 결론: 질문에 대한 직접 답변 한 문장
2. 공통 핵심 인사이트: 여러 행사·기간에서 반복된 방향과 가장 큰 공통 변동
3. 기간별 흐름: 연도별 또는 행사별 차이와 예외
4. 기여 요인: 거래액 변화는 고객수·객단가 효과로, 전환 변화는 트래픽→가입→첫구매 단계로 분해
5. 실행 제안: 시점, 대상, 확인할 지표를 구체적으로 제안
6. 해석 주의: 원인을 단정하지 않고 데이터 범위와 예외를 명시

공통 인사이트는 유효한 비교 기간의 절반 이상에서 같은 상승·하락 방향이 반복될 때만 표현한다. 기준을 충족하지 않으면 `공통 방향 없음` 또는 `연도별 상이`로 답한다. 한 기간만 있으면 공통 인사이트 대신 그 기간의 핵심 변화로 표시한다.

## 계산과 책임 경계

- 수치 계산과 기여도 산식은 기존 브라우저 대시보드 공식이 담당한다.
- Gemini는 제공된 집계 근거만 해석하며 근거에 없는 수치·원인을 만들지 않는다.
- 공통 방향 여부와 유효 기간 수는 브라우저에서 결정해 근거에 포함한다.
- 기존 자동 요약, 지표 정의, 주차·전년 비교 규칙은 변경하지 않는다.
- Gemini 장애 시에도 같은 선별 근거로 기존 산식 인사이트를 표시한다.

## 오류 처리

- 요청한 기간에 데이터가 없으면 0으로 해석하지 않고 데이터 범위 밖임을 표시한다.
- 일부 기간만 유효하면 유효 기간만 분석하고 누락 기간을 명시한다.
- 요청한 지표가 해당 원천에서 지원되지 않으면 다른 지표로 대체하지 않고 지원되지 않는 이유를 표시한다.
- Gemini 반환값이 요청 범위를 벗어나면 클라이언트 검증에서 제거하거나 안전한 로컬 해석으로 전환한다.

## 검증 기준

1. 지표 없는 추석 비교 질문은 핵심 지표 8개만 포함하고 앱·푸시·KPI·상품 근거가 없어야 한다.
2. `첫구매 거래액` 질문은 거래액 행만 근거에 있어야 한다.
3. `앱푸시 수신동의` 질문은 요청 앱 지표만 포함해야 한다.
4. `카테고리별 첫구매 고객수` 질문은 core 고객수와 카테고리 상품 근거만 포함해야 한다.
5. `모든 실적` 질문은 기존처럼 전체 영역을 포함해야 한다.
6. 동일 방향 행사와 혼합 방향 행사에서 공통 인사이트 판정이 각각 일치해야 한다.
7. 실제 2026-09-27 백업에서 화면 근거 수치와 기존 공식 계산값이 일치해야 한다.
8. Gemini 연결·실패 두 경로에서 근거 범위가 동일해야 한다.

## 배포

관련 단위·브라우저·실백업 회귀 테스트와 Python/JavaScript 문법 검사를 통과한 뒤 `main`에 배포한다. 공개 페이지에서 요청하지 않은 앱·푸시 근거가 사라지고 요청 지표만 표시되는지 재확인한다.
