# 지표와 기간 정의

## 공식 기준

공식 화면 산식은 `dashboard.html`의 `MET`, `compute()`, `sumBase()`다. `build_data.py`는 합산 가능한 기본값과 비율의 분자를 저장하며, 화면이 선택 기간에 맞춰 파생 지표를 다시 계산한다.

| 화면 지표 | 산식/원천 | 표시 |
|---|---|---|
| 첫구매 거래액 | 전체관점 `_첫구매` 거래액 합 | 백만원 |
| 첫구매 고객수 | 전체관점 `_첫구매` 고객수 합 | 명 |
| 첫구매 객단가 | 첫구매 거래액 / 첫구매 고객수 | 원 |
| 비회원 트래픽 | 일별 트래픽 합. 주별 일평균은 해당 주 일별 합계 / 데이터 일수 | 건수 |
| 가입자수 | 가입자수 합 | 명 |
| 가입률 | 가입자수 / 비회원 트래픽 | %, 소수 둘째 자리 |
| 당일가입 CR | 당일가입 첫구매자 / 가입자수 | %, 소수 첫째 자리 |
| 첫구매율 | 태블로 첫구매율을 트래픽 가중해 재집계 | %, 소수 둘째 자리 |

회원구분(전체, 당월신규, 기가입신규, 기존)은 거래액·고객수·객단가에만 적용한다. 채널과 회원구분을 여러 개 고르면 차트는 조합별 계열을 만들고, 요약 카드는 선택 목록의 첫 번째 조합을 사용한다.

## 집계 원칙

- 일평균은 합산형 지표의 기간 합계를 실제 데이터 일수로 나눈다.
- 누계는 월·주 기간 합계다. 일별은 하루 값이므로 일평균과 누계가 같다.
- 객단가와 비율은 기간의 분자·분모를 각각 합한 뒤 나눈다.
- 요청 기간의 절반 미만만 데이터가 있으면 값을 표시하지 않는다.
- 일자 raw가 없고 주별 raw가 있는 합산형 지표는 주 합계에서 이미 아는 일자 값을 빼고 남은 날짜에 균등 배분한다. 추정값은 화면에서 기울임으로 표시한다.
- 주별 트래픽 기반 지표(`tr`, `jr`, `fpr`)도 화면에 표시된 월~일의 일자 raw를 합산해 계산한다.

## 기간과 비교

- 주는 ISO 월요일~일요일이다.
- “M월 N주차”의 월과 주차는 그 주 목요일의 월과 일자를 기준으로 한다.
- 최신 주가 7일 미만이면 현재 들어온 날짜만 집계하고, 전년은 그 날짜들의 364일 전 동일 요일만 비교한다. 완결 주차도 동일하게 7개 일자 raw를 합산한다.
- 전년 동기간은 364일 전 같은 요일이다.
- 전월 비교는 완료된 월이면 전월 전체, 진행 중인 월이면 같은 일수까지만 비교한다.
- 전주는 7일 전 같은 요일들, 전일은 하루 전이다.
- 기준 기간이 비어 있거나 유효하지 않으면 실적이 존재하는 가장 최근 기간을 사용한다.
- 주별/일별 범위는 기준 기간에서 끝나는 8·13·26주 또는 14·30·60·90일 범위다.
- KPI는 화면 비교 토글과 무관하게 항상 전년 동기 누적과 비교한다.

## KPI

KPI 설정 형식은 `kpi.example.js`가 기준이다. 실제 목표는 공개하지 않는 `kpi.js`에 둔다.

- 기본 실적 원천은 신규회원실적대시보드의 당년신규 총 첫구매 거래액·고객수다.
- 해당 원천이 없으면 전체관점의 당월신규+기가입신규를 사용한다.
- 목표 일평균 = 연간 목표 / 해당 연도 일수
- 남은 기간 필요 일평균 = (연간 목표 - 누적 실적) / 남은 일수
- 목표 가입률 = 가입자수 목표 / 비회원 트래픽 목표

## 상품·앱 관련 지표

- 상품 구성은 조직 카테고리별 첫구매 실적의 양수 행만 사용한다. 취소·반품 음수와 0원 행은 제외한다.
- 상품CR = 상품관점 고객수 / 상품UV다. 조직 카테고리와 상품관점 상품군은 분류가 달라 서로 섞지 않는다.
- 앱푸시 수신동의율(신규회원) = 신규 앱푸시 수신동의 / 가입자수
- 앱 신규 설치 대비 수신동의율 = 신규 앱푸시 수신동의 / 앱 신규 설치
- 유효회원 대비 수신동의율 = 수신동의 회원 / 유효회원수. 분자는 앱 설치자 기준, 분모는 앱 설치 무관 기준이다.
- 앱푸시 회원 수와 Push 활성 기기는 기간 말 값이고, 추가·이탈·순증은 기간 합이다.

## 알려진 원천 한계

- 트래픽 원천에는 사용자 식별자가 없어 날짜 사이의 방문자 중복 여부를 이 대시보드에서 검증하거나 제거할 수 없다. 모든 기간은 제공된 일자 raw를 합산한다.
- 상품 원천은 전체 첫구매 거래액의 일부만 매핑될 수 있으며, 주문고객수는 상품별 합이라 중복될 수 있다.
- 2025년 앱 설치 raw가 없어 앱 설치 지표의 전년비는 비어 있다.
- 앱 미설치자의 수신동의 여부는 원천에 없어 표시하지 않는다.
- PUSH 원천의 알려진 오류일과 재분류 규칙은 `dashboard.html`의 “지표 정의 · 집계 기준”을 보존한다.
